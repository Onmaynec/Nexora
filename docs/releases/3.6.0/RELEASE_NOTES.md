# Nexora 3.6.0 — Connect\n\n> Status: implementation candidate. This document does not authorize stable publication. The signed release remains blocked until every item in the verification record and external evidence ledger is complete.\n\n## User result\n\nNexora 3.6.0 adds a server-scoped personal connection layer: contact requests, block-aware profiles, privacy-filtered presence and read receipts, one-to-one WebRTC voice calls, minimal call history and access-validated profile deep links.\n\n## Implemented scope\n\n- Additive contact request lifecycle with `pending`, `accepted`, `rejected`, `cancelled` and `expired` states.\n- Cursor-paginated, rate-limited user search with profile privacy filtering.\n- Presence policies `everyone`, `contacts`, `shared_rooms` and `nobody`; last-seen precision and read-receipt visibility.\n- Authenticated, participant-bound Socket.IO call signaling with sequence checks, expiry and bounded payloads.\n- Short-lived HMAC TURN credentials generated by Local Server; no static TURN secret is shipped to clients.\n- Windows, Browser/PWA and Android-compatible WebRTC :
voice UI with microphone selection, mute, output selection where supported, timer, reconnect state and terminal cleanup.\n- Minimal SQLite call history without media, SDP, ICE candidates or call content.\n- Safe profile deep links bound to Server ID and object ID.\n\n## Data migration\n\nLocal Server upgrades schema 9 to additive schema 10 before network listen. Migration performs source integrity verification, free-space validation, a verified pre-migration backup, one SQLite transaction, target integrity verification and downgrade protection.\n\nAdded tables:\n\n- `connect_privacy`\n- `connect_call_history`\n- `connect_idempotency`\n- `connect_audit`\n\n## Compatibility\n\nApplication API v3 is extended additively. Existing direct conversations remain valid. Contacts are an additional social policy layer. Legacy Trust/MLS history remains read-only and is not converted into server-readable plaintext.\n\n## Security boundary\n\nLocal Server remains authoritative for contact transitions, privacy filtering, call membership, session binding, block policy, signal validation, rate limits and call history. Voice media is peer-to-peer or TURN-relayed and is not recorded by Nexora Server.\n\n## Required production configuration\n\n- Production TURN URLs and a strong `NEXORA_TURN_SECRET`.\n- Signed Windows and Android release credentials.\n- Installed acceptance environments for Windows 10/11, supported Browser/PWA and supported Android devices.\n- Independent security review and completed cross-platform call matrix.\n\n## Current release blockers\n\nSee `docs/releases/3.6.0/RELEASE_VERIFICATION.md` and `release-evidence/current.json`. No `v3.6.0` tag, GitHub Release or updater metadata may be published while a blocker remains.\n
