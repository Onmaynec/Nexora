# Nexora 3.7.0 — Community Hub

**Статус:** экспериментальные исходники в `main`. Стабильный `v3.7.0` не опубликован; версия пакета остаётся `3.6.0` до полного релизного процесса.

## Как включить

Сервер Communities выключен по умолчанию. Для локальной тестовой среды:

```powershell
$env:NEXORA_EXPERIMENTAL_COMMUNITIES = "1"
npm start
```

Ранее существовавшая опция `experimentalCommunities: false` явно запрещает включение независимо от окружения. Рекомендована отдельная резервная копия SQLite.

## Поиск и вступление

Сообщество не отображается в каталоге до включения опции `discoverable` владельцем. `GET /api/v3/communities/discovery/search` выполняет поиск по имени/описанию с лимитом 1–30, курсором и экранированием символов SQL LIKE. Членство, блокировка и закрытые каналы не раскрываются. Ответ содержит только имя, описание, ID и количество участников.

Пользователь может подать заявку из каталога. Только участник с правом `members.moderate` может просматривать список ожидающих заявок и принимать решение. Каждая модераторская операция выполняется в транзакции: проверяются бан, membership и лимит 10 000 участников. До одобрения заявитель не может читать каналы. Не более 1000 одновременно открытых заявок, повтор после отказа или выхода — не ранее 24 часов.

| Метод | API | Параметры |
|---|---|---|
| GET | /api/v3/communities/discovery/search | q, limit, cursor |
| POST | /api/v3/communities/:id/hub/join-requests | {} |
| GET | /api/v3/communities/:id/hub/join-requests | limit, cursor; только модератор |
| PATCH | /api/v3/communities/:id/hub/join-requests/:userId | decision=approve/reject |

## Правила

Владелец публикует до 3000 символов текста правил. Текст версионируется только при изменении. Новый участник должен принять текущую редакцию перед отправкой сообщения; после изменения правил подтверждение требуется заново. Проверка производится на сервере внутри транзакции отправки. Владелец исключён из подтверждения.

| Метод | API | Назначение |
|---|---|---|
| GET | /api/v3/communities/:id/hub | правила, редакция, статус принятия и видимость |
| PATCH | /api/v3/communities/:id/hub | только владелец: rulesText, discoverable |
| POST | /api/v3/communities/:id/hub/rules/accept | версия правил: version; устаревшая версия вызывает 409 |

## Календарь событий

Владелец, модератор или роль с правом `events.manage` может создавать и отменять события. Встреча назначается на будущее — от одной минуты до 366 дней, продолжительность не более 24 часов. Название до 120 символов, описание до 1000. Допускается до 200 активных событий на сообщество.

Участники отмечают RSVP: `going`, `interested` или `declined`. Счётчики и личный статус доступны в календаре, отменённые события остаются в истории. API использует стабильную пагинацию по `starts_at,id`; без членства в сообществе календарь не читается.

| Метод | API | Назначение |
|---|---|---|
| GET | /api/v3/communities/:id/hub/events | limit, cursor, mode=upcoming/past |
| POST | /api/v3/communities/:id/hub/events | title, description, startsAt, endsAt |
| PATCH | /api/v3/communities/:id/hub/events/:eventId | status=cancelled |
| PUT | /api/v3/communities/:id/hub/events/:eventId/rsvp | status=going/interested/declined |

## Совместимость и технические ограничения

Модуль работает с дополнительными экспериментальными таблицами `community_hub_settings`, `community_rule_acceptance`, `community_join_requests`, `community_events` и `community_event_rsvps`. Он не повышает версию основной схемы SQLite 10 и не затрагивает старые комнаты.

Интеграционный набор `test/communities-hub.test.cjs` покрывает каталог, закрытый доступ, подтверждение правил, заявки, роли, RSVP и пагинацию при одинаковом времени. Проверка issue #125 покрывает перестановку только видимых каналов и категорий с сохранением приватных элементов.

Оставшиеся задачи: #123 (пагинация очереди жалоб), #124 (полный журнал модерации), нагрузочные испытания, полноценный защищённый realtime, дополнительные антиспам-механизмы, установочные проверки клиентов и публикация версий #77/#78. Объединение кода с `main` не является публикацией GitHub Release.
